# 10万インプ超えツイート ライブラリ

10万インプレッション以上を記録したツイートの保管庫。
新しいツイートを受け取ったら、下の「ツイート一覧」に追記していく。

## 記録フォーマット

各ツイートは以下の形式で記録する。数値が不明な項目は `-` とする。

```
### NNN. <一行の要約タイトル>

- 投稿日: YYYY-MM-DD
- インプレッション: 000,000
- いいね / RT / リプ / ブックマーク: - / - / - / -
- URL: <あれば>
- 形式: 単発 / スレッド / 画像付き / 動画付き / 引用RT
- タグ: #テーマ1 #テーマ2

**本文**

> （ツイート本文をそのまま引用ブロックで記録）

**伸びた要因メモ**

- （フック、構成、時間帯、時事性など気づいたこと）
```

## 使い方

- 追記のとき: ユーザーがツイートを送ってきたら、このファイルの末尾に追記してコミット＆プッシュする。
- 引き出すとき: ユーザーが「あのツイート」「〇〇系のやつ」と聞いてきたら、このファイルを読んで該当するものを返す。テーマ・形式・数値で横断的に探せるようにタグを必ず付ける。
- 分析のとき: 共通パターン（フックの型、文字数、投稿時間帯、画像の有無）を聞かれたら、一覧全体から傾向をまとめる。

**伸びた要因メモ**

- 冒頭フックが「みんな言いませんが」＝業界の暗黙知を明かす形。秘匿情報の開示を宣言している。
- 「方法は3つしかありません」と数を先に言い切る型。読者に読み終わりの見通しを与えて離脱を防いでいる。
- 話題性のある固有名詞（ポケモン30th記念box）を冒頭に置き、その時期の検索・関心と接続している。
- 常識の逆張り。「利益が出ない時に買う」「定価より高いプレ値で買う」という直感に反する主張が、続きを読ませる引力になっている。
- 定価5500円 / 取引価格8000円という具体的な数字で、抽象論を一気に腹落ちさせている。
- 1行が短く改行が多い。スマホでの視認性が高く、長文でもスクロールが軽い。
- ①②が資金前提であることを認めた上で、③で「資金がない人」向けの逃げ道を用意している。読者層を切り捨てず裾野を広げる構成。
- 着地が自分のサロン（「基本うちのサロンで大量回収は全部これ」）。ノウハウを出し切った直後に、自然な導線を置いている。
